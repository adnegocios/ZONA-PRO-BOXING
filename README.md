# Zona Pro Boxing

Control de estudiantes, asistencia, pagos, cierre de caja, vencidos e inactivos.

- `index.html`: la página (se publica con GitHub Pages).
- `config.js`: aquí se pega la dirección de la aplicación web de Google Apps Script.
- `apps-script/Code.gs`: código de la API que guarda todo en Google Sheets.

Los datos viven en una hoja de cálculo de Google y no en este repositorio.
La página pide una clave de acceso la primera vez que se abre en cada equipo.
No subas la clave ni los datos de estudiantes a este repositorio (es público).
